Watermark notes & sources

Anthropic’s Claude watermark (SynthID-Text, live since Aug 2026) is a statistical bias in token choices: there are no hidden characters, so the zero-width scan catches other tools’ injections, not the mark itself. The mark survives copy-paste and light edits; only real rewrites degrade it, so the disruption % above is the honest proxy for how far your edits go. Detection API announced by Anthropic (Aug 12, 2026), not yet callable. C2PA metadata applies to files (.png/.jpg/.svg), not pasted text. En dashes (Sohna–Alwar, 2001–2004) are legit ranges; flagged, never touched.

Code mode runs a vanilla port of Flux’s MessageRenderer engine: fixMalformedTags, repairLatex (hallucinated \int{x}, \big{, unicode math), markdown blocks, tables, lists, KaTeX + raw-LaTeX fallback, Prism syntax highlighting. The renderer is the detector here: anything it has to repair gets flagged.
